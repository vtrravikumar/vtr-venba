# Book Assets

This directory contains image and other media assets referenced by the root-level `manuscript.md`.

## Conventions

- Keep the final cover artwork in `assets/cover/`.
- Keep illustrations, photographs, diagrams, and other interior images in `assets/images/`.
- Use descriptive, stable filenames in lowercase kebab-case, for example `cover-front.png` or `part-ix-stillness.jpg`.
- Reference assets from the manuscript using repository-relative paths, and verify that VTR Press resolves those paths in its actual build workflow before publication.
- Do not commit temporary exports, duplicate drafts, or unlicensed images. Record attribution/licensing where applicable.
- Keep image dimensions, resolution, colour profile, and format aligned with the final print and ebook requirements.

The cover and interior images have not yet been selected. Add them when the content and design are ready.
