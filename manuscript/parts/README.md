# Manuscript Parts

The manuscript will be organised into nine Parts, following the approved structure in [the architecture](../../docs/architecture.md).

Create each Part's source material incrementally. Before writing verses, define the scope of its eight Chapters and add their boundaries to a topic register. Each Chapter has a target of ten paired compositions: one Tamil verse and one English companion verse per pair.

The two language versions should convey a shared central insight without being forced into literal translation. Tamil prosody and the project's English compositional method must be reviewed separately.

Follow the VTR Press manuscript conventions. PDF is the primary planned output; EPUB is optional. This directory contains manuscript source, not the publishing engine.
